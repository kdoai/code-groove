# PRの変更箇所から根拠へ

公開GitHubの固定版を調べた保存済み解析で、左の「PRの変更箇所から根拠へ」を開き、同じリポジトリのPR URLを入力します。Tsugiaiの公開記録と、その変更していない私有コピーでも利用できます。GitHub版との同一性を確認できないローカル提供スナップショットは対象外です。

PRのheadと保存版が一致すれば、変更行からコードを開きます。「変更のある実装」は本体の行範囲との交差、「読取根拠に変更がある実装」は保存済みの根拠を介した関係です。テスト・型・契約・別の説明の根拠も、既存の読取記録で関係を確認できた場合だけ表示します。保存された説明から観察・反証の確認状態・未確認事項を読み、実装を選んで既存の「呼出・返却・利用の根拠」へ進めます。

版が違う場合は、変更行へ古い根拠を割り当てません。「このhead版をAgentで新規解析」は認証と利用枠が必要な明示操作です。固定headの公開リポジトリを既存の取込処理で読み、周辺実装・テスト・契約を含む通常の索引を作ります。差分だけを全調査範囲にはしません。大きなリポジトリは既存の分割規則に従い、選択外は未調査です。

| 確認項目 | 扱い |
|---|---|
| 版 | head・base・保存版を表示。読取前後にhead/baseを照合し、移動時は再読取を案内 |
| 差分 | GitHub Files APIの追加行をheadの行範囲として使用。表示するbaseはPRのbase参照版で、差分起点のmerge-baseを保証しない |
| 削除 | headのコード位置や実行経路を推測せず、GitHubで読む入口を残す |
| 欠落・上限 | 差分なし、追加行数と一致しない差分、先頭300ファイル・各64行範囲・読取根拠96件の省略を明示 |
| 対応なし | 保存済みソースの範囲外、解釈との対応なしを表示。「問題なし」と判定しない |
| 根拠 | 保存された読取記録の関係であり、影響範囲の網羅性・動作・変更の妥当性は未確認 |

PRの読取と根拠表示はGETのみで、新しいモデル要求・ジョブ・ソース更新を行いません。GitHubの公開APIを制限付きで読み、参考先やPRのコードは実行しません。責務の旋律・音量・全体演奏は変更しません。

現在位置を明示し、PRの変更関数から探索を始める発想は、[Codelodyの確認した版](https://github.com/yuki-kobayashi-git/codelody/blob/a06d888dba2906994283afeb13b191b28b76ca00/index.html)を参考にしています。同版にLICENSEは確認できず、コード・音源は流用していません。
