# 二つの関数を比較する

演奏パネルの「二関数を比較」から、同じスナップショット内の二つの関数を選びます。左右のコードと構造の対応を確認し、必要に応じて音を聴きます。

## 比較できるコード

構造比較はTypeScriptの`.ts`関数を対象にします。160行未満、16,000文字以内、512イベント以内の範囲を扱います。PythonとTSXは既存の意味解析で閲覧できますが、構造比較の対象には含めません。

分岐、繰り返し、呼び出し、宣言・代入、return・throwを静的に抽出します。入れ子関数とコールバックは別の単位です。呼び出し先を実行したり、実行時の順序や回数を推測したりしません。

コメントや空白の違いを除き、名前、定数、演算子、引数、参照先を保って対応を探します。構文が同じでも、意味や動作が同じとは限りません。対応を確定できない箇所や未対応の構文は、その状態を表示します。

## コードと音を確認する

比較行を選ぶと、両側の元コードを強調します。「音を使う」を外して、コードと構造の表示だけで操作することもできます。

A、B、A→Bを短く再生できます。同じ呼び出し先には共通のフレーズを使います。区間は手動で進め、対象行と残りを確認します。音に収められない場合はその状態を示し、コードの表示を維持します。

## メモと追加調査

期待・観察・疑問を記録できます。違いに気付いたか、理由を確認できたか、どう判断したかをそれぞれ残します。AIの回答や音の再生によって、人の確認状態が自動で変わることはありません。

保存済みの実解析サンプルへ追加調査を依頼する場合は、ログイン後、自分の私有コピーを保存してから送信します。選んだ両関数を読み直した根拠と、初回説明を維持・修正・保留する理由を返します。模擬教材では新しい実モデル解析を開始しません。

メモは端末のlocalStorageへ保存します。「ローカルJSONに書き出す」から、比較したコードのhash、選択範囲、メモ、確認状態、回答と根拠を出力できます。クラウド同期、複数端末共有、記録のインポートはありません。

## ローカルで試す

[開発手順](DEVELOPMENT.md)で起動すると、短い比較教材とローカル専用の模擬回答を試せます。模擬回答と保存済みのGemini実解析は区別して表示します。

構造比較は、利用者が違いと理由を確かめるための操作です。意味の同一性、動作の正しさ、音による読解の効果を保証しません。
