# プロジェクト紹介

Code Grooveは、既存コードやAI生成コードを引き継ぐ開発者のためのコード理解支援ツールです。Geminiがコードを読み、責務と処理の関係を整理します。利用者はその配置を音とタイムラインで確かめ、気になった箇所からコードと根拠へ戻れます。

追加調査は利用者の明示操作で開始します。改善案を採用するときは差分を確認し、アプリ内のコピーへ反映します。元のリポジトリを変更せず、調査対象のコードも実行しません。

## デモ

[アプリ](https://code-groove-web-a5ygiois2a-an.a.run.app)でTsugiaiの保存済み解析を開きます。演奏、音の選択、根拠コード、Agentの説明を順に確認できます。調査済みの9実装と未調査の範囲を区別して表示します。

## 提出物

GitHubリポジトリ、動作するアプリのURL、プロジェクトの説明、[システム構成図](architecture.svg)、約3分のYouTubeデモ動画を提出します。認証が必要な操作の動作確認情報は、提出先の非公開欄で扱います。

[公式イベントの提出要件](https://zenn.dev/hackathons/google-cloud-japan-ai-hackathon-vol5)に従い、提出した既定ブランチと動作環境を審査終了まで維持します。
