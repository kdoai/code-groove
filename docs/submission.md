# 提出資料 — R14候補

**Code Groove：同じ変更理由のコードを、音からたどる。**

利用者は既存コードやAI生成コードを引き継ぐ開発者です。通常のAIレビューが説明を読むところから始まるのに対し、Code Grooveは責務の配置を聴き、気になった音を選んでコードと根拠へ戻る入口を提供します。速度優位は未実証です。

Geminiはコード・関連・テストをツールで読み、仮説と反証を調べ、根拠付きの意味を提出します。ADKの単一custom Agentで制御し、固定コンパイラが音に変換します。対象コードは実行しません。比較対象、反証の確認状況、判断保留、選択外の範囲を表示します。改善案は人が差分を採用して初めてアプリ内コピーに反映します。

## 審査員が見る順序

1. 主デモの保存済み返品教材を開きます。5実装と解析起点を確認します。
2. 店舗／Webの期限・商品・手数料を聴き比べ、同じ意味キーの音高と二つのコードを確認します。
3. 保存説明と反証の「確認記録なし」を見ます。旧解析を新規解析として紹介しません。
4. Tsugiaiの実在コードを開き、9実装・残り2範囲・実行動作未検証を示します。
5. 新規調査と人の承認の境界、日次上限、保存再現を説明します。動画で未実施の新規解析を演出しません。
