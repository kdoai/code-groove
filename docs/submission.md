# 提出用ドラフト

Code Groove — コードの設計を聴き、根拠をたどり、改善を人が選ぶレビュー・ワークスペース。

対象はTypeScript・Pythonのプロジェクトを理解する開発者やレビュー担当者です。同じ判断が複数のファイルへ散らばる、処理を追うために複数の判断や役割を行き来する、といった設計上の負担はLintだけでは捉えにくい。Geminiが仮説を立て、コード・テスト・呼び出し関係・別の設計理由を読み、根拠付きの意味イベントと構造・読みやすさの指摘を提出します。命名・書式・既知のバグを音楽上の品質スコアへ置き換えることはしません。

DTM型の画面にはディレクトリ階層、ファイル／関数の演奏クリップ、実際に鳴るノート、旋律・和音・低音、大きいコード表示、常設のAgent質問欄が並びます。ドラムは使いません。同じ責務は同じ旋律を持ち、ファイル順と意味で揃えた配置を比較します。懸念のある判断に固定規則の応答を加え、気になる音からコード行と理由へ戻れます。音楽はレビューの位置と構造比較を助けるもので、音だけの正誤判定や安全の保証ではありません。

初期画面に改善後はありません。「Geminiに改善案を依頼」で新しくコードを読み、差分・理由・トレードオフ・必要な確認を提示します。人が却下または採用を選び、採用後に別のスナップショットを再診断して初めて変更前／採用後を聴き比べられます。再診断は懸念の解消を強制せず、同じ責務の旋律を保持します。元コードを保存し、GitHubへの書込みや対象コードの実行はしません。

Cloud Runでwebと非公開workerを実行し、Vertex経由のGemini API（Google Gen AI SDK）のツールループを使用します。Firebase Auth、Firestore、Cloud Storage、Cloud Tasks、Secret Managerを使用。Agentの操作はサーバー管理の読取り・仮説・検証済み差分提出に限定し、所有権・期限・実行権・日次クォータ・トークン予約・停止スイッチで制御します。GitHub ActionsはWIFと検証済みコミットによる配備を使用。Cloud Runは最小0、web最大2、worker最大1。AIを除く月6,000円の予算通知を設定しています（請求の強制上限ではありません）。

URL: https://code-groove-web-a5ygiois2a-an.a.run.app 。審査メールは `reviewer@example.invalid`。管理者がSecret Managerからパスワードを取得し、非公開の動作確認欄へ記入してください。メール受信やソーシャルログインは不要です。

動作確認：初回の実画面案内 → 「サンプルを開く」 → 全体や懸念の前後を再生 → オレンジの音から元コード・判断・別の設計理由を確認 → 「意味で揃える」で同じ旋律を寄せる → ログインして改善案を依頼 → 差分を確認して採用または却下 → 採用後の再診断と変更前後を比較。審査アカウントには今回の本番承認結果も保存されています。保存結果の再生はAI呼出し0件。同じスナップショットの更新も解析を再利用します。

今回の本番検証では、Geminiが3ファイルの変更を提案し、明示的なテスト承認後に独立して再診断しました。3つの責務の旋律は維持され、重複管理への懸念は解消、チャネル別処理の正当な境界は保持されました。これはその実行結果であり、毎回同じモデル判断を保証しません。保存した診断・音楽規則・音源が同じなら、同じ楽譜と発音タイミングを再現します。対象コードの動作保証は別途必要です。

構成図: `artifacts/architecture.png`。編集元、技術スタック、シーケンス、DFD、音楽化、承認フローは `docs/TECHNICAL_GUIDE.md`。3分デモ: `artifacts/code-groove-demo.mp4`。実際の本番Gemini生成・テスト承認・再診断を録画し、ログインを除外、待機を短縮し、差分と採用後画面に静止時間を加えています。音声はその保存楽譜と同じPCMを実際の再生時刻に合わせて再構成。ナレーションはありません。配信用MP4と編集スクリプトをGit管理し、資格情報・生動画・音声は除外します。

再収録は費用とクォータを使うため明示的なopt-inです。既存MP4の閲覧は無料です。別のテストでも消えないよう、収録元は除外ディレクトリ `.local` に保存します。

```powershell
$env:E2E_LIVE_IMPROVEMENT='1'
node scripts/capture-demo.mjs
uv run --with imageio-ffmpeg python scripts/assemble-demo.py
Remove-Item Env:E2E_LIVE_IMPROVEMENT
```

収録は新しい実改善案へのテスト承認を含みます。編集は新しいモデル呼出し0件。字幕と編集時刻は `docs/demo-subtitles.srt` と `artifacts/demo-timing.json` に保存しています。再収録にはPlaywright Chromiumと管理者のSecret Managerアクセスが必要です。
